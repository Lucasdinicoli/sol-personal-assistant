# SOL — Changelog

All notable changes to SOL Public Version are documented here.

## [1.0.0] — Initial Public Release

### Added
- Initial SOL identity and personality.
- Minimal communication principles.
- Personal life dimension management.
- Memory and continuity guidelines.
- Goal setting and micro-goal decomposition.
- Task and schedule management.
- Email, calendar, notes and messaging integration guidelines.
- Optional morning briefing.
- Follow-up and reminder management.
- Daily planning and evening review workflows.
- Weekly reflection and progress tracking.
- Privacy and user control principles.

### Design Principles
- Understand more.
- Organise better.
- Communicate less.
- Respect user autonomy.
- Prioritise practical usefulness over unnecessary interaction.

### Project Status
Experimental public AI assistant instruction set.

Platform-specific functionality depends on the user's AI assistant, available integrations and permissions.
