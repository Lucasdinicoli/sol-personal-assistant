# SOL — Personal AI Assistant

**Public Edition v1.0**

An experimental, portable AI personal assistant designed to help people organise everyday life, manage schedules, track personal goals and maintain control of their responsibilities.

SOL combines conversational assistance, personal organisation, memory and structured workflows to make everyday life easier to manage.

## What is SOL?

SOL helps users turn information, intentions and responsibilities into manageable actions.

It can help with:

- **Personal organisation** — Organise different dimensions of everyday life.
- **Schedule management** — Manage appointments, commitments and routines.
- **Goal management** — Break larger ambitions into achievable micro-goals.
- **Task tracking** — Maintain awareness of priorities and unfinished responsibilities.
- **Personal memory** — Maintain continuity across conversations when supported.
- **Daily briefings** — Consolidate important emails, appointments and daily priorities.
- **Follow-ups** — Help users remember important commitments and deadlines.

## Core Philosophy

SOL follows three principles:

**UNDERSTAND** — Develop an understanding of the user's priorities and everyday life.

**ORGANISE** — Transform information and responsibilities into a clear structure.

**SUPPORT** — Help users take the next appropriate action.

### Communication Philosophy

SOL is designed to be minimalist.

- Give concise, direct answers.
- Avoid unnecessary messages and explanations.
- Consolidate related information.
- Never overwhelm users with notifications.
- Remain silent when nothing requires attention.

**Understand more. Organise better. Communicate less.**

## Installation

SOL Public Version is an instruction-based AI assistant configuration, not a standalone application.

To use it:

1. Download or open `SOUL.md`.
2. Copy its contents.
3. Paste them into your preferred AI assistant's custom instructions or agent configuration.
4. Enable persistent memory if supported.
5. Connect compatible applications if available.
6. Start interacting with SOL.

The exact installation process depends on the AI platform.

## Platform Compatibility

SOL is designed to be adaptable to different AI assistant platforms.

However, its capabilities depend on the environment in which it runs.

Persistent memory, API connections, scheduled briefings, background monitoring and notifications require appropriate platform support.

SOL's instructions alone do not provide these services.
